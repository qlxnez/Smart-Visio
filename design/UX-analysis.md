# Smart Vision — UX-анализ сервисов распознавания объектов

## Цель исследования

Изучить пользовательский опыт взаимодействия с сервисами распознавания объектов по фотографии, выявить их преимущества и недостатки, а также определить решения, которые можно использовать при разработке собственного проекта Smart Vision.

## Анализируемые продукты

- Google Lens (Google Объектив).
- Яндекс — Умная камера.

---

## 1. Пользователь и задача

### Целевая аудитория

- Обычные пользователи, желающие узнать информацию о незнакомом объекте.
- Студенты и школьники.
- Покупатели, ищущие товары по фотографии.
- Туристы, интересующиеся достопримечательностями.
- Люди, интересующиеся растениями и животными.

### Какую проблему решает продукт?

Сервисы позволяют получить информацию об объекте, название которого пользователь не знает. Вместо самостоятельного поиска и составления текстового запроса достаточно сделать или загрузить фотографию.

### Сценарий использования

Пользователь замечает незнакомый предмет, открывает приложение на смартфоне, фотографирует объект и получает информацию о нём.

### Критерий успешного выполнения задачи

Пользователь получил правильное название объекта и необходимую информацию о нём за минимальное количество действий.

---

## 2. Основной сценарий

### Google Lens

1. Открыть Google Lens.
2. Сделать фотографию или загрузить изображение.
3. Выделить интересующий объект при необходимости.
4. Дождаться обработки изображения.
5. Ознакомиться с результатами поиска.

### Яндекс — Умная камера

1. Открыть приложение Яндекса.
2. Перейти в раздел Умной камеры.
3. Сделать фотографию или выбрать изображение из галереи.
4. Дождаться обработки изображения.
5. Просмотреть полученные результаты.

### Особенности взаимодействия

Оба сервиса используют фотографию в качестве основного способа ввода информации. Пользователю не требуется самостоятельно описывать объект.

При тестировании необходимо оценить количество действий, удобство выбора изображения, наличие индикатора загрузки и возможность отмены обработки.

---

## 3. Результат модели

### Google Lens

Результат может быть представлен в виде:

- Названия объекта.
- Похожих изображений.
- Ссылок на сайты.
- Информации о товарах.
- Дополнительных поисковых результатов.

### Яндекс — Умная камера

Результат может содержать:

- Предполагаемое название объекта.
- Похожие изображения.
- Ссылки на интернет-ресурсы.
- Информацию о товарах и магазинах.

### Уверенность модели

Пользователь не всегда получает точную числовую оценку уверенности модели. Из-за этого бывает сложно определить, насколько достоверен результат распознавания.

### Исправление ошибок

При неправильном распознавании пользователь может:

- Сделать новую фотографию.
- Изменить ракурс съёмки.
- Выделить нужный объект на изображении.
- Уточнить поисковый запрос.
- Использовать другое изображение.

### Ограничения

Точность распознавания может зависеть от:

- Качества фотографии.
- Освещения.
- Расположения объекта.
- Наличия посторонних предметов.
- Сложности распознаваемого объекта.

Наличие обратной связи и объяснений результата необходимо дополнительно проверить при тестировании.

---

## 4. Ошибки и пустые состояния

Для проверки поведения сервисов необходимо рассмотреть следующие ситуации:

| Ситуация | Возможная проблема |
| --- | --- |
| Размытая фотография | Неправильное распознавание объекта |
| Плохое освещение | Недостаточно информации для анализа |
| Несколько объектов на фотографии | Определение не того объекта |
| Отсутствие интернета | Невозможность получить результаты поиска |
| Неподдерживаемый файл | Ошибка загрузки изображения |

### Пустое состояние

При первом открытии сервиса пользователь должен понимать, как начать работу: сделать фотографию или загрузить готовое изображение.

### Обработка ошибок

Хороший интерфейс должен сообщать пользователю о возникшей проблеме простым языком и предлагать способы её решения.

Например:

- Сделать фотографию повторно.
- Улучшить освещение.
- Проверить подключение к интернету.
- Загрузить другое изображение.

Фактические сообщения об ошибках будут зафиксированы после тестирования сервисов.

## 6. Выводы

### Общие паттерны

- Использование камеры и галереи.
- Автоматическая обработка изображений.
- Визуальное представление результатов.
- Поиск похожих объектов.
- Возможность повторного распознавания.

### Уникальные особенности

Google Lens ориентирован на универсальный визуальный поиск и взаимодействие с поисковой системой Google.

Умная камера Яндекса ориентирована на визуальный поиск и взаимодействие с сервисами экосистемы Яндекса.

### Возможные недостатки

- Неточное распознавание объектов.
- Отсутствие понятной оценки уверенности модели.
- Зависимость от качества фотографии.
- Большое количество нерелевантных результатов.
- Зависимость от интернет-соединения.

### Что возьмём в проект Smart Vision

- Простой и понятный интерфейс.
- Возможность загрузки фотографии.
- Распознавание объектов с помощью искусственного интеллекта.
- Отображение названия и описания объекта.
- Индикатор обработки изображения.
- Отображение степени уверенности модели.
- Возможность повторного распознавания.
- Понятные сообщения об ошибках.

### Чего будем избегать

- Перегруженного интерфейса.
- Лишних действий пользователя.
- Непонятных сообщений об ошибках.
- Представления предположений модели как достоверных фактов.
- Отсутствия возможности исправить результат.

## Заключение

Smart Vision — проект интеллектуального сервиса для распознавания объектов по фотографии.

Основная задача проекта — предоставить пользователю простой и удобный инструмент для получения информации об окружающих предметах.

При разработке планируется учитывать преимущества существующих сервисов, уделяя особое внимание простоте интерфейса, понятности результатов и удобству взаимодействия с искусственным интеллектом.
